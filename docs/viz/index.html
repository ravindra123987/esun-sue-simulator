LLR + CBFC Packet Viewer

Replays what the link simulator actually did: every frame, every control block and every state change of the two MACs on one 800G link. Frames are drawn to scale; a 1 KB frame is about 10 ns long on a 64 ns link.

Traces are generated by tools/make_traces.py, which runs sim/ with tracing on. Captions come from sim/trace.py and are derived from the events, not written per scenario. Control blocks (8 B) are really 0.08 ns long; they are drawn wider so you can see them.
Model limits (see docs/experiments/llr-cbfc.md): one link, one VC, both ends start initialised, no PCS-status timer.
